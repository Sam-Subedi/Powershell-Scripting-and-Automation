# Windows Commands:
net user: To see local users
net user username:To see detailed information about a specific user account (Example: net user sam or, net user Administrator)
net user Administrator: To see detailed information about the built-in Administrator account
net localgroup: Check the local groups on a Windows machine
net localgroup Administrators: To see the members of a local Administrators group

# Enable PowerShell Remoting: Enable-PSRemoting -Force

(Displays the status and configuration of the Windows Remote Management (WinRM) service)

# Test WinRM connectivity: Test-WSMan SERVER01
(Tests whether the target computer responds to WS-Management requests. Replace SERVER01 with the actual computer name or appropriate hostname.)

# Start an interactive remote PowerShell session: Enter-PSSession -ComputerName SERVER01

# View all available information about local users:
Get-LocalUser | Format-List *  or, Get-LocalUser | Format-Table * or, Get-LocalUser | Out-GridView  

# Get detailed information about all local users: 
Get-LocalUser | Select-Object Name, Enabled, Description, LastLogon, PasswordRequired, PasswordExpires, UserMayChangePassword

# Get detailed information about specefic user: 
Get-LocalUser -Name "Username" | Select-Object Name, Enabled, Description, LastLogon, PasswordRequired, PasswordExpires, UserMayChangePassword

# Get detailed information about members of the local Administrators group: 
Get-LocalGroupMember Administrators | Format-Table Or, Get-LocalGroupMember Administrators | Out-GridView

# To check who is in the Administrators group and whether the local accounts are enabled:
Get-LocalGroupMember Administrators |
    ForEach-Object {
        $name = $_.Name

        try {
            $user = Get-LocalUser -Name ($name -split '\\')[-1] -ErrorAction Stop

            [PSCustomObject]@{
                Name        = $user.Name
                Enabled     = $user.Enabled
                LastLogon   = $user.LastLogon
                Description = $user.Description
                Principal   = $_.Name
                ObjectClass = $_.ObjectClass
            }
        }
        catch {
            [PSCustomObject]@{
                Name        = $name
                Enabled     = "N/A"
                LastLogon   = "N/A"
                Description = "Domain/other account"
                Principal   = $_.Name
                ObjectClass = $_.ObjectClass
            }
        }
    } |
    Format-Table -AutoSize


# Get-CimInstance Cmdlets: 
Get-CimInstance Win32_Bios: Provides BIOS version, serial number, and manufacturer details.
Get-CimInstance Win32_Processor: Provides CPU model, core count, clock speed, and status.
Get-CimInstance Win32_PhysicalMemory: Provides RAM stick sizes, speeds, and manufacturer details.
Get-CimInstance Win32_NetworkAdapterConfiguration: Provides IP addresses, MAC addresses, and network settings.
Get-CimInstance Win32_BaseBoard: Provides motherboard model, manufacturer, and serial number.
Get-CimInstance Win32_VideoController: Provides graphics card (GPU) model and driver information.
Get-CimInstance Win32_StartupCommand: Provides startup commands configured to run automatically when a user logs on or Windows starts.
Get-CimInstance Win32_QuickFixEngineering: Provides a list of installed Windows Updates and patches.

# Discovery & Forensic Gathering:
Get-CimInstance Win32_UserAccount: Provides information about user accounts, including local and domain accounts. Useful for identifying unexpected, disabled, or potentially unauthorized accounts.
Get-CimInstance Win32_UserAccount -Filter "LocalAccount = True": Provides information about local user accounts only.
Get-CimInstance Win32_UserAccount -Filter "LocalAccount = True AND Disabled = False": Provides enabled local user accounts, useful for reviewing accounts that are currently active.
Get-CimInstance Win32_UserAccount -Filter "LocalAccount = True AND PasswordRequired = False": Identifies local accounts that do not require a password.
Get-CimInstance Win32_UserAccount -Filter "LocalAccount = True"|Select-Object Name, Domain, Disabled, Lockout, PasswordRequired, SID: Displays key properties of local accounts, including account name, domain, disabled/lockout status, password requirements, and SID.
Get-CimInstance Win32_GroupUser: Provides an association between user accounts and groups, allowing analysts to investigate group membership and identify accounts belonging to privileged groups such as Administrators.
Get-CimInstance Win32_NetworkConnection: Provides information about network resource connections, such as connections to remote shares.
Get-CimInstance Win32_Product: Provides information about software installed through Windows Installer (MSI), which can be used for software inventory and investigation of unexpected applications.
Get-CimInstance Win32_Share: Provides information about locally configured shared resources, useful for identifying unexpected or overly permissive network shares.

# Hunting for Malware Persistence & Abuse:
Get-CimInstance -Namespace root\subscription -ClassName __EventConsumer: Provides information about WMI event consumers, which can be investigated for persistence mechanisms involving scripts or other actions triggered by WMI events.
Get-CimInstance Win32_ScheduledJob: Provides information about legacy WMI scheduled jobs, which can be reviewed for potential persistence or scheduled activity.
Get-CimInstance Win32_ShadowCopy: Provides information about Volume Shadow Copies, useful for investigating backup/recovery configuration and determining whether shadow copies are present.

# Checking for Suspicious Accounts & Privilege Configuration:
Get-CimInstance Win32_UserAccount -Filter "Disabled = False": Identifies user accounts that are enabled.
Get-CimInstance Win32_UserAccount -Filter "LocalAccount = True": Identifies local user accounts on the computer.
Get-CimInstance Win32_UserAccount -Filter "PasswordRequired = False": Identifies user accounts that do not require a password.
Get-CimInstance Win32_UserAccount -Filter "LocalAccount = True AND PasswordRequired = False": Identifies local user accounts that do not require a password.

# Spotting Malicious Processes & Persistence:
Get-CimInstance Win32_Process -Filter "Name = 'cmd.exe' OR Name = 'powershell.exe'": Provides details on running Command Prompt and PowerShell processes, which can be investigated for suspicious command execution or scripting activity.
Get-CimInstance Win32_Process -Filter "ExecutablePath LIKE '%AppData%'": Identifies processes whose executable path contains AppData, which can be useful for investigating unusual process execution from user-profile locations.
Get-CimInstance Win32_Process | Where-Object { $_.ExecutablePath -like '*\AppData\*' } | Select-Object Name, ProcessId, ParentProcessId, ExecutablePath, CommandLine: Lists processes executing from AppData and displays their process ID, parent process ID, executable path, and command line for further investigation.

# Checking Network & Software Anomalies:
Get-CimInstance Win32_Product -Filter "Name LIKE '%VNC%' OR Name LIKE '%AnyDesk%'": Searches MSI-installed software for names associated with VNC or AnyDesk, which can help identify remote-access software requiring further investigation.
Get-CimInstance Win32_LogicalDisk -Filter "DriveType = 4": Provides information about connected network drives, useful for identifying network resources and investigating potential lateral-movement activity.
Get-ItemProperty "HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*" , "HKLM:\Software\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*" |
Select-Object DisplayName, DisplayVersion, Publisher, InstallDate: Enumerates software registered in common Windows uninstall registry locations.
Get-ItemProperty "HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*" , "HKLM:\Software\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*" |
Where-Object { $_.DisplayName -match 'VNC|AnyDesk' } | Select-Object DisplayName, DisplayVersion, Publisher, InstallDate: Searches registered installed software for names associated with VNC or AnyDesk, which can help identify installed remote-access software requiring further investigation. 

# Hunt (AppData Process Execution & Lineage Trace):
A.Scan for processes running from AppData:
Get-CimInstance Win32_Process -Filter "ExecutablePath LIKE '%AppData%'" | Select-Object Name, ProcessId, ParentProcessId, ExecutablePath, CommandLine
(Identifies processes whose executable path contains AppData and displays their process ID, parent process ID, executable path, and command line for investigation.)

B.Identify the parent process that spawned the suspicious process:
Get-Process -Id (Parent Process ID Number) Example: Get-Process -Id 4812
(Retrieves information about the process associated with the specified parent process ID.)

# Network & Service Persistence Hunting:
Get-CimInstance Win32_Service: Provides information about Windows services, including their names, states, startup modes, and executable paths, useful for investigating suspicious or unexpected services.
Get-CimInstance -Namespace root\StandardCimv2 -ClassName MSFT_DNSClientCache: Provides cached DNS resolution information, which can help identify recently resolved domain names and investigate potentially suspicious domains.

# Get recent WMI Event ID 5858 events:
Get-WinEvent -LogName "Microsoft-Windows-WMI-Activity/Operational" |
    Where-Object {$_.Id -eq 5858} |
    Select-Object -First 10 |
    Format-List

# Get recent WMI Event ID 5858 events:
Get-WinEvent -FilterHashtable @{
    LogName = 'Microsoft-Windows-WMI-Activity/Operational'
    Id      = 5858
} -MaxEvents 10 | Format-List
