
============================================================
1. USER MANAGEMENT
============================================================

1. Get-ADUser
Command:
Get-ADUser -Identity username

Example:
Get-ADUser -Identity sam.smith

What it does:
Shows basic information about an Active Directory user.

When to use it:
Check whether a user exists and view basic account information.


2. Get-ADUser -Properties *
Command:
Get-ADUser -Identity username -Properties *

Example:
Get-ADUser -Identity sam.smith -Properties *

What it does:
Shows detailed user attributes.

When to use it:
Troubleshoot an account or inspect user attributes.


3. Get-ADUser -Filter *
Command:
Get-ADUser -Filter *

Example:
Get-ADUser -Filter *

What it does:
Lists Active Directory users.

When to use it:
View users in the domain.


4. Get-ADUser with Select-Object
Command:
Get-ADUser -Filter * | Select-Object Name,SamAccountName,Enabled

Example:
Get-ADUser -Filter * | Select-Object Name,SamAccountName,Enabled

What it does:
Displays selected user properties.

When to use it:
Create simple reports or quickly check account status.

2. CREATE AND MODIFY USERS
============================================================

5. New-ADUser
Command:
New-ADUser

Example:
New-ADUser `
    -Name "Sam Smith" `
    -GivenName "Sam" `
    -Surname "Smith" `
    -SamAccountName "sam.smith" `
    -UserPrincipalName "sam.smith@abc.local" `
    -Path "OU=Sales,OU=Employee,DC=abc,DC=local" `
    -AccountPassword (Read-Host "Enter Password" -AsSecureString) `
    -Enabled $true

What it does:
Creates a new Active Directory user.

When to use it:
Use it when onboarding a new employee or creating an approved account.


6. Set-ADUser
Command:
Set-ADUser -Identity username

Example:
Set-ADUser -Identity sam.smith -Department "Sales" -Title "Sales Representative"

What it does:
Changes attributes of an existing user.

When to use it:
Update department, title, description, or other supported user attributes.

PRACTICAL HELPDESK WORKFLOW
============================================================

EXAMPLE 1: USER CANNOT LOG IN

Step 1: Check the account.

Get-ADUser -Identity sam.smith -Properties Enabled,LockedOut,PasswordExpired

Step 2: If locked, unlock it.

Unlock-ADAccount -Identity sam.smith

Step 3: Reset the password if required.

$Password = Read-Host "Enter New Password" -AsSecureString
Set-ADAccountPassword -Identity sam.smith -NewPassword $Password -Reset

Step 4: Force a password change.

Set-ADUser -Identity sam.smith -ChangePasswordAtLogon $true

Step 5: Check group membership if the user can log in but cannot access something.

Get-ADPrincipalGroupMembership sam.smith


EXAMPLE 2: COMPUTER HAS A DOMAIN ISSUE

Step 1: Check domain membership.

Get-CimInstance Win32_ComputerSystem |
    Select-Object Name,Domain,PartOfDomain

Step 2: Test the secure channel.

Test-ComputerSecureChannel -Verbose

Step 3: Test connectivity to the domain controller.

Test-NetConnection dc01.abc.local -Port 389


EXAMPLE 3: GROUP POLICY ISSUE

Step 1: Force Group Policy update.

gpupdate /force

Step 2: Check applied policies.

gpresult /r

Step 3: Generate a detailed report.

gpresult /h C:\Temp\GPReport.html


EXAMPLE 4: WINDOWS TROUBLESHOOTING

Step 1: Check Windows services.

Get-Service

Step 2: Check recent System events.

Get-WinEvent -LogName System -MaxEvents 50

Step 3: Check installed updates.

Get-HotFix | Sort-Object InstalledOn -Descending

Step 4: Gather computer information.

Get-ComputerInfo
